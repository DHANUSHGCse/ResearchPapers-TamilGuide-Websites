Dense Retrieval என்றால் என்ன?

AI ஒரு கேள்விக்கு பதில் தேட Wikipedia மாதிரி பெரிய database-ல search பண்ணும். இதை Dense Retrieval னு சொல்வாங்க. Search பண்ணும் முன்னாடி ஒரு முக்கியமான decision — எந்த size-ல text எடுப்போம்?

PART 02 / 08
Proposition என்றால் என்ன?
3 defining rules மற்றும் examples
Definition: Proposition = ஒரு atomic expression — ஒரே ஒரு fact, minimum size, தனியா படிச்சாலும் புரியும்.

மூன்று Rules:

1
ஒரே உண்மை மட்டும் இருக்கணும்
ஒரு proposition-ல ஒரே ஒரு fact இருக்கணும். இரண்டு facts இருந்தா — அது இரண்டு propositions!
✗ "கோபுரம் 3.99° சாய்ந்துள்ளது மற்றும் 56m உயரம்" — இரண்டு facts!
✓ "பிசா கோபுரம் 3.99° சாய்ந்துள்ளது" — ஒன்னே ஒன்னு!
2
Minimum size — இன்னும் பிரிக்க முடியாது
இன்னும் சின்னதா பிரிக்க முடியாம இருக்கணும். பிரிக்க முடிஞ்சா — அதுவும் proposition இல்ல!
✗ "அருண் படிச்சான், விளையாடினான்" — இரண்டா பிரிக்கலாம்!
✓ "அருண் படிச்சான்" — இதை இன்னும் பிரிக்க முடியாது!
3
Self-contained — தனியா புரியணும்
"it", "he", "அது", "அவன்" மாதிரி words வேண்டாம். பதிலா full name சொல்லணும். வெளியே context இல்லாம புரியணும்!
✗ "அது 3.99° சாய்ந்துள்ளது" — "அது" என்னன்னு தெரியல!
✓ "பிசா கோபுரம் 3.99° சாய்ந்துள்ளது" — crystal clear!

4 Steps — எப்படி Build பண்ணாங்க:

1
Wikipedia எடுத்தாங்க
2021 October Wikipedia dump. Tables, images எல்லாத்தையும் நீக்கி, clean text மட்டும் வச்சாங்க. கோடான கோடி வார்த்தைகள்!
RAW DATA
2
GPT-4 — Teacher Model
42,000 passages-ஐ GPT-4-கிட்ட கொடுத்தாங்க. "இந்த பத்தியை proposition-ஆ பிரி" னு கேட்டாங்க. இந்த 42k examples training data ஆச்சு!
TEACHER MODEL
3
Flan-T5 — Propositionizer (Student)
GPT-4 miga expensive — முழு Wikipedia-க்கு use பண்ண முடியாது! அதனால GPT-4 output வச்சு சின்ன Flan-T5 model train பண்ணாங்க. F1 score: 0.822 — 98%+ accurate!
STUDENT MODEL
4
முழு Wikipedia Run!
Propositionizer வச்சு whole Wikipedia process பண்ணினாங்க. 500 GPU hours — 20 நாள் non-stop! Result: 25.7 கோடி propositions!
FACTOIDWIKI READY
Knowledge Distillation = Expert (GPT-4) கத்துக்கொடுத்ததை வச்சு, சின்ன model (Flan-T5) கத்துக்கிட்டது. Sachin Tendulkar கத்துக்கொடுத்தா, நீ உன் தம்பிக்கு கத்துக்கொடுப்பே — அதே மாதிரி!

Limitations + Final Wrap Up
Honest mistakes மற்றும் complete summary

Paper-ஓட 3 Limitations:

⚠️
Wikipedia மட்டும் test பண்ணாங்க
News articles, research papers, books — இதுல proposition எப்படி work ஆகுதுன்னு test பண்ணல. Other databases-ல different results வரலாம்!
→ Future: Other databases test பண்ணணும்
🌐
English மட்டும்
Tamil, Hindi, French, Chinese — other languages-ல proposition work ஆகுமா? தெரியல! ஒரே ஒரு மொழியில் மட்டும் prove பண்ணினாங்க.
→ Future: Multilingual explore பண்ணணும்
🔀
Multi-hop Questions-ல Fail ஆகும்
"Layer Cake movie main character பேர் என்ன?" — actor பேரும், character பேரும் இரண்டு வேற propositions-ல இருக்கும். இரண்டையும் combine பண்ண proposition alone போதாது!
→ Future: Multi-hop reasoning integrate பண்ணணும்
